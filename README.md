# Car Rental CRM Pro — учебный проект ООП

Десктопное приложение администратора проката автомобилей на Python и PyQt5.

## Запуск (Запушил релиз v1.0.0)

```bash
python -m pip install -r requirements.txt
python main.py
```

## Основные разделы

- Обзор автопарка и ближайших возвратов.
- Календарь бронирований с проверкой пересечения дат.
- Выдача и возврат автомобилей с фиксацией пробега.
- Финансы: зарегистрированные платежи, остаток задолженности и экспорт CSV.
- Списки автомобилей и клиентов.

## Соответствие требованиям ТЗ
Все расписано в файле requirements_mapping.md

## Проверки

Запустить проверки из каталога проекта:

```bash
python -m unittest tests_compliance.py -v
python -m compileall -q .
```

Для графического запуска требуется установленный PyQt5. Проверки логики и совместимости JSON можно выполнить без запуска окна.

## Демо-доступ

Если в хранилище нет сотрудников, создаётся демонстрационный пользователь `admin`. В учебной версии вход имитируется; это не production-аутентификация.
