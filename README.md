# Car Rental CRM Pro — учебный проект ООП

Десктопное приложение администратора проката автомобилей на Python и PyQt5.

## Запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

## Основные разделы

- Обзор автопарка и ближайших возвратов.
- Календарь бронирований с проверкой пересечения дат.
- Выдача и возврат автомобилей с фиксацией пробега.
- Финансы: зарегистрированные платежи, остаток задолженности и экспорт CSV.
- Списки автомобилей и клиентов.

## Соответствие требованиям ТЗ

- Бизнес-сущности реализованы пользовательскими классами, наследуемыми от `AbstractEntity`.
- Сущности реализуют `validate`, `to_dict`, `from_dict`, сравнение `__eq__`, представление `__repr__` и `__str__`; у сущностей есть свойства с геттерами и сеттерами.
- Для коллекций и внутренних отображений применяется `EntityCollection` и пользовательский `ObjectMap` (хранит пары в списке, а не в `dict`).
- В интерфейсе есть более десяти пользовательских компонентов/диалогов на базе Qt; компоненты размещены с помощью Qt Layouts.
- При подтверждённом закрытии приложения записывается отчёт `report.txt` с колонками `login`, `time_in`, `time_out`. Время имеет формат `%d.%m.%Y %H:%M:%S`.
- `data.json` сохраняет прежнюю структуру. Встроенные JSON-объекты используются только на границе сериализации/десериализации, поскольку это формат хранения файла; бизнес-коллекции не реализованы через `dict`.

## Проверки

Запустить проверки из каталога проекта:

```bash
python -m unittest tests_compliance.py -v
python -m compileall -q .
```

Для графического запуска требуется установленный PyQt5. Проверки логики и совместимости JSON можно выполнить без запуска окна.

## Демо-доступ

Если в хранилище нет сотрудников, создаётся демонстрационный пользователь `admin`. В учебной версии вход имитируется; это не production-аутентификация.
